Observed, non-blocking

Found during today’s pass or earlier phases, deliberately left as-is because fixing them was outside each phase’s stated scope. Listed here so nothing quietly gets lost.

Seeded pandit name duplicates the “Pandit” honorific in generated titles
The ramesh-sharma fixture’s full_name is itself “Pandit Ramesh Sharma”, and the title formula prepends “Pandit ” again → “Pandit Pandit Ramesh Sharma.” This is seed-data content, not a code defect — it reproduces identically on the client-rendered page today, unrelated to the SEO work in any phase.
Missing fallback image for pandits with no photo
/assets/img/pandits/default.jpg is referenced as a fallback in normalize.ts but was never added to public/, producing an occasional 404. Predates this initiative; noted during the Phase 8 performance pass and left as a follow-up ticket.
No frontend test runner
Phase 9’s coverage is entirely backend (real Express app + real DB). Seo.tsx and structuredData.ts’s correctness is validated indirectly via the server-side metadata mirror’s own tests, plus this audit’s live browser checks — not via a component test suite, which does not exist in this project.
